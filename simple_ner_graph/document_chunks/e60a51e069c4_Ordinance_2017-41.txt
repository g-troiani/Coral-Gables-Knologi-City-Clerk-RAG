--- DOCUMENT METADATA AND CONTEXT ============================= **DOCUMENT IDENTIFICATION:** - Document Type: DOCUMENT - Source File: 2017-41 - 11_14_2017.pdf - Processed Stage: Stage 1 (OCR Extraction) - Conversion Date: 2025-07-05 01:29:13 **DOCUMENT CONTENT:** ==================== ## CITY OF CORAL GABLES, FLORIDA ## ORDINANCE NO. 2017- 41 AN ORDINANCE OF THE CITY COMMISSION OF CORAL GABLES ADOPTING AND ENACTING A NEW CODE FOR THE CITY OF CORAL GABLES, FLORIDA; PROVIDING A PENALTY FOR THE VIOLATION THEREOF; PROVIDING FOR THE MANNER OF AMENDING SUCH CODE; AND PROVIDING WHEN SUCH CODE AND THIS ORDINANCE SHALL BECOME EFFECTIVE; AND PROVIDING FOR A SEVERABILITY CLAUSE, CODIFICATION, AND PROVIDING FOR AN EFFECTIVE DATE. WHEREAS, the Code entitled " Code of the City of Coral Gables, Florida," published by Municipal Code Corporation, consisting of Chapters 1 through 117 each inclusive, is adopted; and WHEREAS, unless another penalty is expressly provided, every person convicted of a violation ofany provision of the Code or any ordinance, rule or regulation adopted or issued in pursuance thereof, shall be punished by a fine. Except as otherwise provided by law or ordinance, a person convicted of a violation ofthe Code shall be punished by a fine ofnot more than $ 500.00, imprisonment for a term not exceeding 60 days, or any combination thereof. Except as otherwise provided by law or ordinance; with respect to violations of the Code that are continuous with respect to time, each day that the violation continues is a separate offense and with respect to other violations, each act constitutes a separate offense; and WHEREAS, additions or amendments to the Code when passed in such form as to indicate an intention to make the same a part of the Code shall be deemed to be incorporated in the Code, so that reference to the Code includes the additions and amendments; and WHEREAS, ordinances adopted after July 11, 2017, that amend or refer to ordinances that have been codified in the Code shall be construed as ifthey amend or refer to like provisions ofthe Code; ## NOW, THEREFORE, BE IT ORDAINED BY THE COMMISSION OF THE CITY OF CORAL GABLES, FLORIDA: SECTION 1. That the foregoing recitals are hereby ratified and confirmed as being true and correct and are hereby made a specific part of this ordinance upon adoption hereof. SECTION 2. That the City Commission does hereby adopt and enact a new code for the City of Coral Gables, Florida; providing a penalty for the violation thereof and providing for the manner of amending such code. SECTION 3. This version of the Code supersedes all prior versions of the City Code and is the operative Code except as amended, revised or corrected in the future. SECTION 4. That this Ordinance shall become effective within (10) ten days following its passage and adoption herein. PASSED AND ADOPTED THIS FOURTEENTH DAY OF NOVEMBER, AD., 2017.
