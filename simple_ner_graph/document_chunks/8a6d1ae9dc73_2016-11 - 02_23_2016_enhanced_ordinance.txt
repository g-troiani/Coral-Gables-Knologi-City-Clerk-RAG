Code enforcement officer to present cases. Each case before the code enforcement board shall be presented by a code enforcement officer or member of the administrative staff of the city. The city attorney or designee may serve as counsel to the code enforcement board or may represent the city by presenting cases before the code enforcement board, but in no case shall the same individual attorney serve in both capacities at the same hearing.
